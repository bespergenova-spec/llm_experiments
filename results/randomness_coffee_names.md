# Опыт 2: случайность — «Придумай название для кофейни» ×3

**Запрос (дословно, без системного промпта пользователя):** `Придумай название для кофейни`

**Как запускали:** три независимых субагента Claude Code с чистым контекстом, по одному запросу каждому.
Это приближение к «трём новым чатам»: у субагентов есть служебная инструкция Claude Code, а настоящих новых чатов с API-ключом здесь не было.

## Выводы

- Ответы не одинаковые, но и не независимые: модель каждый раз выбирает из одного и того же узкого набора идей (зерно, крема, обжарка, ристретто, бариста, уют).
- Самое вероятное название почти не меняется: «Зерно и Пар» выпало дважды дословно. «Хвост» списка более случайный: 15 из 19 уникальных названий встретились только один раз.
- Случайность возникает при выборе каждого следующего токена из распределения вероятностей. Начало ответа сильно задаёт остальное, поэтому формат и структура повторяются почти без изменений.
- Для творческих задач одного запуска мало: если нужно разнообразие, стоит просить много вариантов сразу или перегенерировать.

## Ограничения

- Выборка всего 3 запуска, температура и остальные параметры генерации неизвестны.
- Субагенты Claude Code не идентичны чистому чату: у них есть служебная системная инструкция.
- Модель одна и та же, поэтому результат может отличаться на других моделях.
