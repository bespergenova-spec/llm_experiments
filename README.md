# llm_experiments

Небольшие опыты с языковыми моделями: токены, случайность, температура, top-k и top-p.
Все результаты воспроизводимы скриптами из этого репозитория, подробные таблицы лежат в `results/`.

## Что внутри

| № | Тема | Скрипт | Результаты |
|---|---|---|---|
| 1 | Токенизация одной фразы: английский, русский, русский латиницей, казахский | [tokenizer_ru_vs_en.py](tokenizer_ru_vs_en.py) | [results/tokenizer_ru_vs_en.md](results/tokenizer_ru_vs_en.md) |
| 2 | Случайность: «Придумай название для кофейни» ×3 | запуск вручную через субагентов | [results/randomness_coffee_names.md](results/randomness_coffee_names.md) |
| 3 | Токенизация разных типов текста (регистр, числа, код, URL, эмодзи, пробелы) | [tokenizer_text_types.py](tokenizer_text_types.py) | [results/tokenizer_text_types.md](results/tokenizer_text_types.md) |
| 4 | Температура (симуляция softmax) | [temperature_softmax.py](temperature_softmax.py) | [results/temperature_softmax.md](results/temperature_softmax.md) |

Рядом с каждым `.md` лежит `.json` с теми же данными.

## Как запустить

```bash
pip install -r requirements.txt
python tokenizer_ru_vs_en.py
python tokenizer_text_types.py
python temperature_softmax.py
python topk_topp.py
python tokenizer_models.py
```

Опыт 6 скачивает файлы токенайзеров с Hugging Face. Чтобы посчитать токены текущих Claude, задайте `ANTHROPIC_API_KEY` (необязательно, по умолчанию эта строка пропускается).

## Главные результаты

### Опыт 1. Один и тот же текст на разных языках

Токенов на три фразы одинакового смысла, по сравнению с английским (cl100k_base — токенайзер GPT-4, o200k_base — GPT-4o и новее):

| Токенайзер | Русский | Русский латиницей | Казахский |
|---|---|---|---|
| cl100k_base | 1.9–3.0x | 1.7–2.4x | 2.7–4.1x |
| o200k_base | 1.2–2.0x | 1.6–2.1x | 1.1–1.8x |

- Русский в старом токенайзере режется на слоги и буквы, в новом разрыв сильно меньше.
- Казахские буквы `қ`, `ң`, `ү`, `ө`, `ә` в cl100k распадаются на байты.
- Транслит выгоден только в старом токенайзере, в новом кириллица дешевле.

### Опыт 2. Случайность

Один и тот же запрос задан трём независимым «чатам» (субагентам Claude Code с чистым контекстом).

- Главный выбор: «Зерно и Пар» дважды, один раз «Зерно & Час» — всегда слово «Зерно».
- «Крема» (или «Крем») есть во всех трёх списках.
- Из 19 разных названий 15 встретились лишь по одному разу.
- Вывод: ответы разные, но не независимые. Самые вероятные идеи повторяются, «хвост» списка случайный.

### Опыт 3. Типы текста

- `strawberry` режется на 3 токена (`[str] [aw] [berry]`), поэтому модели трудно считать буквы.
- Пробел входит в токен: ` strawberry` — один токен, а то же слово без пробела — три.
- Числа режутся по три цифры (`[123] [456] [789] [0]`), отсюда неточная арифметика «в уме».
- Составной эмодзи `👨‍👩‍👧` — 5 символов, но 13 токенов в cl100k и 8 в o200k.
- Серии пробелов и переводов строк — по одному токену, поэтому код с отступами относительно дёшев.

### Опыт 4. Температура (симуляция)

Вероятности по формуле `p_i = exp(z_i / T) / Σ exp(z_j / T)` для 12 названий кофейни. Лидер — «Зерно и Пар»:

| T | Доля лидера | Шанс, что 3 чата дадут одно и то же | В среднем разных ответов из 3 |
|---|---|---|---|
| 0 | 100% | 100% | 1.0 |
| 0.5 | 73% | 40% | 1.7 |
| 1.0 | 41% | 8% | 2.4 |
| 2.0 | 22% | 1.8% | 2.7 |

Температура не добавляет новых идей, а лишь перераспределяет вероятности между уже возможными.

### Опыт 5. Top-k и top-p (симуляция)

- Top-k оставляет фиксированное число лучших вариантов, top-p подстраивается под форму распределения.
- При T=1.5 без отсечения редкие варианты выпадали 73 раза из 1000, а с top-p=0.9 — ни разу, при этом разнообразие среди остальных вариантов сохранялось.
- top-k=1 равно температуре 0: ответ всегда один и тот же.

### Опыт 6. Токенайзеры разных моделей

Сумма токенов по трём фразам (английский во всех моделях — 33 токена), в скобках — отношение к английскому:

| Модель | Русский | Русский латиницей | Казахский |
|---|---|---|---|
| GPT-4 (cl100k) | 76 (2.30x) | 63 (1.91x) | 104 (3.15x) |
| GPT-4o / 4.1 / 5 / o-серия (o200k) | 48 (1.45x) | 57 (1.73x) | 46 (1.39x) |
| gpt-oss | 48 (1.45x) | 57 (1.73x) | 46 (1.39x) |
| Claude 1/2 (старый) | 84 (2.55x) | 72 (2.18x) | 107 (3.24x) |
| Qwen3 | 56 (1.70x) | 63 (1.91x) | 88 (2.67x) |
| DeepSeek-V3 | 54 (1.64x) | 66 (2.00x) | 68 (2.06x) |
| Mistral Nemo | 51 (1.55x) | 61 (1.85x) | 57 (1.73x) |
| Gemma 3 | 43 (1.30x) | 59 (1.79x) | 57 (1.73x) |
| Llama 3.1 | 54 (1.64x) | 61 (1.85x) | 85 (2.58x) |

Токенайзер текущих Claude здесь **не измерен**: он не опубликован, токены считаются только через API (`count_tokens`). Строка про Claude 1/2 — это старый токенайзер, по нему нельзя судить о современных моделях.

## Ограничения

- Опыты 1, 3 и 6 используют только три коротких фразы или несколько образцов, выводы ориентировочные.
- Опыт 2: три запуска, субагенты Claude Code отличаются от настоящих новых чатов (у них есть служебная системная инструкция), температура и параметры генерации неизвестны.
- Опыты 4 и 5: логиты **иллюстративные**, подобраны по частотам из опыта 2 и не взяты у реальной модели. Математика температуры, top-k и top-p настоящая, конкретные проценты нет.
- Казахский перевод написан моделью, носитель его не проверял.
- Для Gemma 3 и Llama 3.1 использованы зеркала токенайзеров на Hugging Face, а не оригинальные закрытые репозитории.
